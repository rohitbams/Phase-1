▶ C01: FCA / Wallet Technology Approach ✅ RESOLVED
RESOLVED
✅ Resolution Confirmed

Date: 27 May 2026
Source: RD document for Rohit Coin Wallet 27_5_2026.doc.pdf
Decision: 1:1 fiat-backed wallet (NOT blockchain)

Original Contradiction

Source Statement Reference
BRD "The coin should be based around Ethereum system. It will be a 3rd Party API. KO will create its own blockchain." BRD 3 Jan 2026, Page 5
Wallet & Coin UX "The coin is a 1 to 1 fiat rate (currency) which is backed by the users at phase 1" Wallet & Coin UX doc, Line 7
Coin Wallet (LATEST) "The coin is a 1to1 fiat rate (currency) which is back by the users at phase 1" RD document 27 May 2026 ✅

Confirmed Implementation

  • Architecture: Internal double-entry ledger (NOT blockchain)
  • Wallet Type: Self-custody wallet with 1:1 fiat backing
  • FCA Compliance: Partner with licensed provider (Stripe/Mangopay)
  • Transaction Types: Top-up, Gift, Purchase, Entry Fee, Winnings, Cash-out, Go Live, Nudge Play
  • Database Schema: Wallet + Transaction tables (double-entry)
📋 Impact on SDD

This resolution validates the entire wallet/transaction data model in the SDD. No blockchain infrastructure required. System Design Document proceeds with PostgreSQL ledger implementation.

▶ C04: Real-Time Concurrency Ceiling 🔴
BLOCKING
Source Participant Limit Reference
BRD "two players to an infinite number of players" BRD Page 4, "Klashes"
Gaming Mechanic "unlimited number of participants" Line 166, Super Klasher definition
BRD (Multiverse) "For a forum of 100,000 klashers, split into different simulations" BRD Page 7, "Time sequence requirements"

Engineering Reality

"Unlimited" is not buildable. Every system has a ceiling determined by:

  • WebSocket connection limits (~10K per server instance)
  • Real-time broadcast latency (O(N) fan-out)
  • Audio synchronization tolerance
Working Assumption
  • Standard Klash: 1,000 max participants (single instance)
  • Super Klash: 10,000 max participants (load balanced)
  • Mega Events: 100K+ via "multiverse" sharding (Phase 3+)

Resolution Required: Confirm realistic Phase 1 ceiling with Lincoln.
