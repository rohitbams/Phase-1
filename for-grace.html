# KlashOut

KlashOut is a music battle competition platform where users compete in real-time "Klashes." Two users play 30/60/90-second song snippets, and spectators vote for the winner. Winners earn Klash Coins and climb leaderboards.

Total views to build: 47 unique views across all features and tiers.

User Tiers

KlashOut has three user tiers. Each tier unlocks additional features.

Tier Labels

AT = All Tiers (Klasher, Independent Klasher, Super Klasher)

KT = Klasher Tier (Basic/Free tier only)

IT = Independent Klasher Tier (Mid tier and above)

ST = Super Klasher Tier (Premium tier only)

Tier 1: Klasher (Free)

Access: Browse music, compete in klashes, vote, earn coins, spend coins in-app.

Restrictions: Cannot upload music, cash out, host group events, or go live.

Tier 2: Independent Klasher

Access: Everything from Tier 1 plus upload music, monetize plays, host up to 50-person klashes, go live, cash out.

Restrictions: Cannot set entry fees, host tournaments, or earn hosting fees.

Tier 3: Super Klasher

Access: Everything from Tier 2 plus host unlimited events, charge entry fees, run tournaments, earn hosting percentage, access analytics.

Restrictions: None.

# Views by Tier

All Tiers (AT) — 33 Views

1. Authentication (4 views)

  1. Landing Screen: App logo, tagline, Login button, Register button.
  2. Login Screen: Email/phone input, password input, "Forgot password" link, Login button.
  3. Registration Screen: Username input, email/phone input, password input, verification code input, Register button.
  4. Password Reset: Email input, verification code input, new password input, Confirm button.

2. Music Library (5 views)

  1. Browse Screen: Search bar, genre filters, song grid/list, persistent music player footer.
  2. Search Results: Filtered song list, sorting options (popularity, recent, alphabetical).
  3. Music Player: Song title, artist name, album art, play/pause, progress bar, volume, next/previous.
  4. Playlists: Create playlist button, playlist grid/list, playlist detail view with songs.
  5. Add to Playlist: Modal showing user's playlists, Create new playlist option.

3. Klashing (8 views)

  1. Browse Klashes: Live klash cards showing title, participants, viewer count, "Live" badge, Join button.
  2. Start a Klashout (Setup): Select song from library, title input, tags input, description textarea, duration selector (30/60/90 sec), cover image upload, participant limit, commenting toggle.
  3. Matchmaking: Genre selection grid, duration selection (30/60/90 sec), "Go Online" button.
  4. Waiting Screen: "Searching for opponent..." message, animated loading indicator, Cancel button.
  5. Klash Playback & Voting: Two player cards (left/right), song title and artist for each, audio waveform visualization, countdown timer, current round indicator, Vote buttons (one per player), vote count per player, real-time vote updates, spectator count, comment stream.
  6. Result Screen: Winner announcement, final vote count, coins won/lost, points gained, View History button, Play Again button.
  7. Klash History: List of past klashes showing date, opponent, result (W/L/D), song used.
  8. Direct Challenge: Search for user, Send Klash Request button, notification when request received.

4. Profile & Social (5 views)

  1. Profile Screen: Avatar, username, bio, join date, followers count, following count, win/loss/draw record, klash history, playlists.
  2. Edit Profile: Avatar upload, username edit, bio textarea, privacy toggle (public/private), Save button.
  3. Followers/Following: List of users with avatar, username, Follow/Unfollow button.
  4. Notifications: Tabs for Likes, Comments, New Followers. List showing avatar, username, action, timestamp.
  5. Follow Button: Toggle state (Follow/Following), tap to unfollow confirmation.

5. Messaging (2 views)

  1. Messages Tab: List of conversations showing avatar, username, last message preview, timestamp, unread badge.
  2. Conversation View: Message bubbles (sent/received), text input, Send button, timestamp per message. When starting a new message, includes user search field at top.

6. Wallet & Economy (5 views)

  1. Wallet Screen: Coin balance (large display), transaction history list, Top Up button, Cash Out button (IT/ST only).
  2. Transaction History: List showing type (purchase/gift/winnings/cash-out), amount, date, from/to user.
  3. Top Up Flow: Amount selector (preset amounts + custom), payment method selection, card input (via Stripe), Confirm button.
  4. Cash Out Flow (IT/ST only): Amount input, bank account details, minimum amount warning, fee display, Confirm button.
  5. Send Coins: User search, amount input, optional message, Send button.

7. Leaderboards (2 views)

  1. Leaderboard Screen: Tabs for Global, Weekly, and by Genre (Hip-Hop, Rock, Funk, Independent Music, etc.).
  2. Leaderboard List: Rank number, avatar, username, points, change indicator (up/down arrows).

8. Settings (3 views)

  1. Settings Menu: Privacy settings, notification preferences, account settings, help/terms, logout.
  2. Privacy Settings: Profile visibility (public/private), message settings (everyone/followers only).
  3. Upgrade Account: Tier comparison, pricing, Subscribe button (takes to payment flow).

Independent Klasher and Above (IT) — 9 Views

9. Music Upload (4 views)

  1. Upload Button: Center tab in bottom navigation (IT/ST only).
  2. Upload Flow: Audio file picker, song name input, genre dropdown, artist name input, tags input, terms checkbox, Upload button.
  3. Upload Progress: Progress bar, percentage, Cancel button.
  4. Music Portfolio: List of uploaded songs with plays count, purchases amount, earnings amount.

10. Go Live (5 views)

  1. Go Live Button: Primary action in profile menu (IT/ST only).
  2. Go Live Setup: Stream title, cover image, genre, Start Live button.
  3. Live Streaming (Performer): Camera feed, viewer count, comment stream, Gift notifications, End Stream button.
  4. Live Viewing (Audience): Stream video, host name, viewer count, comment input, Send Gift button, Like button.
  5. Live Indicator: "Live" badge on profile when user is streaming.

Super Klasher Only (ST) — 5 Views

11. Entry Fee & Stakes (1 view)

  1. Entry Fee Input (on Start Klashout Setup): Entry fee amount input field (ST only, added to view 3.2).

12. Tournaments (4 views)

  1. Host Tournament Button: Primary action on Home screen (ST only).
  2. Tournament Setup: Title, format selection (elimination/round-robin/swiss/free-for-all), entry fee, prize pool, participant limit, start time.
  3. Tournament Bracket: Visual bracket showing matchups, current round, winners advancing, live status.
  4. Tournament Dashboard: List of hosted tournaments, participant count, prize pool, engagement metrics.

# Tier Restrictions

Locked Feature Behavior

When a user at a lower tier attempts to access a locked feature, the system should show an upgrade prompt. Locked features should be visible but disabled (greyed out or with a lock icon), not hidden.

Features Locked by Tier

Feature Required Tier
"Upload your own music" button IT (Independent Klasher or above)
Music portfolio (earnings view) IT (Independent Klasher or above)
"Go Live" button IT (Independent Klasher or above)
Cash-out to bank IT (Independent Klasher or above)
Host klashes with 50+ participants IT (Independent Klasher or above)
"Set entry fee" on klash setup ST (Super Klasher only)
"Host a tournament" button ST (Super Klasher only)
"My Dashboard" (analytics) ST (Super Klasher only)
Host unlimited participants ST (Super Klasher only)
