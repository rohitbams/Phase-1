Quick Reference Data | 20 July 2026

Document Purpose

This document provides quick reference tables for controlled vocabularies, enumerations, and key data structures used throughout the KlashOut platform.

User Tiers

Tier Color (BRD) Key Permissions Coin Receiving Threshold

  • Compete in klashes
  • Browse music catalogue
  • Vote as spectator
  • Follow other users

  • All Klasher permissions
  • Upload own music

  • Host Go Live Showcase

Snippet Durations: 30 seconds, 60 seconds, or 90 seconds (set per klash).

Klash State Machine

Each klash follows this finite state machine (see DD-007):

State Duration Actions Next State
MATCHMAKING Until 2 players matched System pairs users by genre READY
READY 5 seconds Both players confirm COUNTDOWN
COUNTDOWN ⚠️ TBD (Lincoln) Visual countdown PLAYING_1
PLAYING_1 30/60/90s First Klasher's snippet plays DECISION_WINDOW
DECISION_WINDOW ⚠️ TBD (Lincoln) Second Klasher: stick or switch PLAYING_2
PLAYING_2 30/60/90s Second Klasher's snippet plays VOTING
VOTING ⚠️ TBD (Lincoln) Spectators vote CALCULATING
CALCULATING <2s Backend tallies votes RESULT
RESULT 10s Winner displayed COMPLETED
COMPLETED — Final state, archived —

Note: Server is authoritative. Clients cannot skip states.

Transaction Types

All wallet transactions stored in single Transaction table with type discriminator (see DD-009).

Type From Wallet To Wallet Trigger
TOP_UP NULL (external) User wallet User purchases coins via Stripe
GIFT User wallet A User wallet B User A gifts coins to User B
MUSIC_PURCHASE User wallet (buyer) User wallet (artist) User purchases track from Independent Klasher
KLASH_ENTRY User wallet Klash wallet (pot) User enters Super Klash with entry fee
KLASH_WINNINGS Klash wallet (pot) User wallet (winner) Klash ends, pot distributed to winner(s)
HOST_FEE Klash wallet (pot) User wallet (Super Klasher) Super Klasher's host fee from pot
GO_LIVE User wallet (spectator) User wallet (performer) Spectator tips performer during Go Live Showcase
NUDGE_PLAY User wallet (nudger) System wallet (KO revenue) User pays to use Nudge Play mechanic
CASH_OUT User wallet NULL (external) User cashes out to bank account via Stripe

Status Values: PENDING, COMPLETED, FAILED, REVERSED

Standard API Response Codes

Code Meaning Usage
200 OK Successful GET, PATCH, DELETE
201 Created Successful POST (resource created)
204 No Content Successful DELETE (no response body)
400 Bad Request Invalid input, validation error
401 Unauthorized Missing or invalid JWT
403 Forbidden Authenticated but insufficient permissions (e.g., Klasher trying to upload music)
404 Not Found Resource does not exist
409 Conflict Duplicate resource (email already exists, klasher_name taken)
422 Unprocessable Entity Business logic error (insufficient balance, voting window closed)
429 Too Many Requests Rate limit exceeded
500 Internal Server Error Unexpected server error
503 Service Unavailable Maintenance mode, database down
